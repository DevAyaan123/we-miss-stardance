# We Miss Stardance 

A nostalgic tribute site built to capture and recall the best memories of **Stardance**. This project was specially created for **Hack Club** as a dedicated space for all things Stardancers!

## Description
This project is a trip down memory lane for the Stardance community. It features:
* A complete collection of memories, facts, and highlights **all about Stardancers**.
* A hidden **surprise** built specifically to celebrate the Stardance legacy.

## Built With
* **HTML** - Structured entirely with clean, semantic markup.

## How to Run the Program
You can run this project locally in just a few steps:
1. **Copy the code** from the main HTML file.
2. **Paste it** into any HTML editor (like VS Code, Notepad++, or Replit).
3. **Save the file** as `index.html`.
4. **Open the file** in any web browser to view it.
